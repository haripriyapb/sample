# 📊 Financial Sales Analysis Dashboard

## 📌 Project Overview

This project analyses financial sales data using Microsoft Excel to identify sales trends, profitability, customer segments, and regional performance.

---

## 🎯 Project Objectives

- Analyse sales performance
- Evaluate product profitability
- Compare sales across countries
- Build an interactive dashboard

---

## 🛠️ Tools Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Conditional Formatting
- XLOOKUP
- SUMIFS

---

## 📂 Dataset

**Source:** Microsoft Financial Sample Dataset

The dataset contains financial sales transactions including:

- Product
- Country
- Segment
- Sales
- Profit
- Units Sold
- Date

---

## 📈 Dashboard Features

- KPI Cards
- Sales Trend Analysis
- Profit Analysis
- Country-wise Sales
- Product Performance
- Interactive Slicers

---

## 💡 Key Insights

- Government segment generated the highest revenue.
- Paseo is the highest-performing product.
- Sales vary significantly across countries.
- Profitability differs by product category.
